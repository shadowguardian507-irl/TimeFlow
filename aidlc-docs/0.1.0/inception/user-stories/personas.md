# User Personas

## Persona: Time Tracker (Primary)

### Role

Knowledge worker who needs to log time to ActiTime for project tracking and billing purposes.

### Goals

- Accurately track time spent on tasks throughout the workday
- Minimize effort required to prepare ActiTime entries
- Account for overhead/administrative time without losing it
- Quickly reference and reuse common recurring tasks

### Pain Points

- Forgetting what was worked on during the day
- Overhead tasks (desk setup, meetings) don't map directly to ActiTime categories
- Manually calculating how to distribute overhead time is tedious
- Typing the same task names repeatedly
- ActiTime's hierarchical categories are cumbersome to navigate

### Context

- Works on multiple projects/tasks daily
- Uses ActiTime for official time tracking (required by organization)
- Has recurring tasks that happen daily/weekly
- Needs to account for all time but some tasks don't fit ActiTime's structure
- Works primarily on macOS

### Behaviors

- Prefers to log time as tasks happen rather than at end of day
- Sometimes forgets to track and needs to backfill
- Values efficiency and minimal friction in tools
- Wants data in a format ready to copy to ActiTime
